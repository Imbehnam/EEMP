# Academic Operations

## Structure
AcademicYear → Term → Subject/Course → CourseOffering/ClassGroup → Timetable/Lessons → Enrollment → Attendance/Assessment → Grade Approval → Report Card.

## Class definition versus offering
A reusable class/course template is not the same as a scheduled offering for a particular term, branch, teacher, capacity, and student roster.

## Teacher management
Profiles, qualifications, contracts (if in scope), branch affiliations, subject capability, assignments, availability, substitutions, and effective dates.

## Grading
Support configurable grading schemes, weighted assessments, grade bands, rounding, missing/absent/exempt states, moderation, approval, publication, correction, and historical snapshots.

## Report cards
- Template per tenant/academic level/locale.
- Versioned generation.
- Controlled approval and publication.
- Parent/student access checks.
- PDF generation and audit.
- Corrections generate a new version and retain prior history.
- Explain grading formula and publication timestamp.
