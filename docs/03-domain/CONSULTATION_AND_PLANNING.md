# Consultation, Support, and Academic Planning

## Consultation and support
Model service type, staff skill, availability, duration, buffer, capacity, booking window, cancellation policy, location/mode, payment requirement, meeting provider, participant list, and status.

Concurrency-safe booking is mandatory. A slot must be atomically reserved; UI availability is advisory only.

## Case privacy
Counseling notes may be highly sensitive. Separate scheduling metadata from private case notes; apply least privilege, explicit assignment, access logging, retention policy, and export restrictions.

## Academic planning
Planning request → eligibility → fee/invoice/payment (policy-defined) → assignment → discovery/session → plan draft → review → approval/publication → milestones/follow-up.

Plan versions and authorship must be retained. Student-facing plan visibility must be explicitly selected; private counselor notes are not automatically exposed.
