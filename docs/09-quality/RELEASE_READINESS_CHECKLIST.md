# Release Readiness Checklist

- [ ] Product requirements and open decisions approved.
- [ ] Legal/privacy review for target jurisdictions completed.
- [ ] Tenant and branch isolation penetration tests passed.
- [ ] Authentication, MFA policy, and privileged access reviewed.
- [ ] Payment provider certification and reconciliation tested.
- [ ] SMS consent, opt-out, sender registration, and delivery tested.
- [ ] Online meeting privacy and link controls tested.
- [ ] Data export, retention, deletion, and offboarding tested.
- [ ] Backup restore and disaster recovery exercise completed.
- [ ] Monitoring, alerting, on-call, and incident response ready.
- [ ] Localization and RTL/LTR reviewed by native speakers.
- [ ] Accessibility audit completed for critical journeys.
- [ ] Load and resilience tests passed.
- [ ] Terms, privacy notice, DPA, and customer support policy ready.
- [ ] Pricing, quotas, trial, billing, grace, and suspension behavior approved.
- [ ] Support access workflow and audit review enabled.
