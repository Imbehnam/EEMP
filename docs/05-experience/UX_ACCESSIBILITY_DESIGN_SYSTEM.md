# UX, Accessibility, and Design System

## Design system
Tokens for color, typography, spacing, radius, elevation, responsive breakpoints, focus, status, and density. Components must support RTL/LTR, keyboard interaction, screen readers, and localization expansion.

## Accessibility target
WCAG 2.2 AA for critical journeys. Validate forms, dialogs, tables, calendars, charts, video controls, color contrast, focus order, keyboard navigation, labels, and error announcements.

## Critical journeys to prototype
Tenant onboarding; branch switch; student enrollment; class scheduling; grade entry/publication; invoice/payment; parent access; consultation booking; planning request; referral approval; locale switch; card/report download.

## UX artifacts to create during discovery
Information architecture, role-based navigation matrix, low-fidelity wireframes, responsive behavior, design tokens, component inventory, and usability acceptance criteria.
